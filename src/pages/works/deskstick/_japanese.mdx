## 特徴

### 付箋を iCloud で同期する
付箋は iCloud で同期されます。Mac・iPhone・iPad・Apple Vision Pro のどの端末からでも同じ付箋を開けます。端末ごとのローカルデータベースを持たない設計なので、「どの端末の内容が最新か」を気にする必要がありません。

### オフラインでも書ける
機内や地下鉄など、ネットワークが届かない場所で編集した内容は端末に保持され、接続が戻ったときに iCloud へ自動的に反映されます。圏外だからといって書きかけが失われることはありません。

### メニューバーからクイック入力（macOS）
メニューバーアイコンをクリックすると、その場で書けるクイック入力が開きます。`⌘⏎` で保存すると、そのまま付箋としてデスクトップに貼り付きます。アプリを切り替えることなく、思いついた瞬間に書き留められます。

### すべての付箋を Organizer で見渡す（macOS）
Organizer は2ペイン構成です。左の一覧から付箋を選ぶと、右のペインでそのまま編集・削除できます。付箋の数が増えても、1枚ずつウィンドウを開かずに中身を確認して回れます。

### 常に最前面
付箋はピン留めできます。ピン留めした付箋は他のアプリを操作している間も常に最前面に表示されます。ピンアイコンのほか `⌘P` でも切り替えられます。

### 色分けできる
付箋の色を設定でき、この色も iCloud で同期されます。「仕事用」「個人用」「実験中」を色で瞬時に区別できます。

### Apple Intelligence で要約タイトル（macOS 26 以降）
設定でオンにすると、付箋の内容を要約した短いタイトルが、ウィンドウのタイトルと Organizer の一覧に表示されます。要約は Mac の中で完結し、内容が外部に送信されることはありません。

### メニューバーと Dock の表示を選べる（macOS）
設定ウィンドウ（`⌘,`）から、メニューバーに常駐させるか Dock にアイコンを出すかを切り替えられます。どちらか一方は必ず表示されるので、アプリを見失うことはありません。

### ホーム画面・ロック画面ウィジェット（iPhone / iPad）
最新の付箋をホーム画面に置いておけます。複数の付箋を並べる「付箋リスト」と、選んだ付箋 1 枚を大きく見せる「付箋ひとつ」の 2 種類があり、いずれも小・中・大の 3 サイズに対応します。ロック画面には、タップですぐ新規作成できる丸型ウィジェットと、最新の付箋を表示する横長ウィジェットを置けます。ウィジェットをタップすれば、その付箋がアプリ内で直接開きます。

### リスト表示とグリッド表示（iPhone / iPad）
一覧はリスト表示とグリッド表示を切り替えられます。選んだ表示モードは次回の起動時にも引き継がれます。

## 対応デバイスと動作環境

Mac・iPhone・iPad・Apple Vision Pro 向けに **App Store で配信中** です。macOS 版は Homebrew（`brew install --cask krgpi/tap/deskstick`）でも導入できます。付箋は iCloud でそのまま同期されるので、Mac で書きかけたプロンプトの続きを iPhone で開く、といった使い方が可能です。

| 項目 | 内容 |
|------|------|
| 対応 OS | macOS 13.0 以降 / iOS・iPadOS 16.0 以降 / visionOS |
| 必要なもの | 端末にサインイン済みの iCloud アカウントと、有効な iCloud Drive |
| 同期 | Apple の iCloud（CloudKit）経由。アカウント登録・ログインは不要 |
| データの扱い | 開発者のサーバーは経由しません。広告・トラッキングもありません（[プライバシーポリシー](/works/deskstick/privacy/)） |

## AI時代の活用例 — プロンプトと出力の一時メモに

DeskStick は、生成 AI（ChatGPT / Claude / Gemini など）を日常的に使うエンジニアやライター、プロダクトマネージャーにとって、以下のような使い方ができます。

### よく使うプロンプトのスニペット置き場として
「コードレビュー用」「議事録要約用」「英訳用」など、繰り返し使うプロンプトのテンプレートを 1 枚 1 プロンプトで付箋にしておけば、ブラウザやチャットアプリの間を行き来するときにコピー＆ペーストの起点として常に手元に置いておけます。色分けで「仕事用」「個人用」「実験中」などを瞬時に区別できます。

### Slack / メール / チャット投稿の下書きとして
勢いで書いて送信ボタンを押す前に、いったん付箋に書き出して読み直す——その一拍が「言わなきゃよかった」を防ぎます。送信先のチャット欄ではなく付箋に下書きしておけば、誤送信や誤爆を避けつつ、推敲してから貼り付けられます。重要な顧客対応・上司への報告・センシティブな返信ほど、この下書き運用が効きます。

### ピン留めで常に開きっぱなしのスクラッチパッドとして
ピン留めした付箋は他のアプリ作業中もずっと最前面に居続けるので、思いついたことを即座に殴り書きできるスクラッチパッドになります。会議中のメモ、調査中のリンクや数字、後で考えたい To-Do——「あとで整理する用の置き場」が画面の隅に常駐していると、作業の手を止めずに思考を逃がせます。

### AI 出力の一時的なスクラッチパッドとして
AI が生成したコードスニペットや文章のドラフトを、エディタやドキュメントに貼り付ける前に「いったん寝かせて見比べたい」「複数バージョンを比較したい」というケースは多いものです。DeskStick はそうした **LLM 出力のスクラッチパッド（捨ててもよいメモ）** として機能し、ピン留めしておけば常に最前面に表示されたまま比較作業ができます。

### 端末をまたいだ AI ワークフローの同期
自宅の Mac で書きかけたプロンプトの続きを、外出先の MacBook や iPhone で続ける、といった使い方も iCloud 同期によりシームレスに可能です。AI を使った作業は「思考の断片を素早く保存し、後で別の場所から拾い上げる」ことの繰り返しなので、デバイスを跨いで同期される付箋との相性は非常に良いです。

### Apple 純正「スティッキーズ」との違い
macOS には標準で「スティッキーズ」アプリがありますが、DeskStick は **iCloud 同期** と **メニューバーからのクイックアクセス** を備えており、AI を使った高頻度のメモ取りに最適化されています。

## 使い方
### メニューバーから操作する（macOS）
  メニューバーからすべての付箋を一覧で確認するウィンドウの表示と、新しい付箋の作成ができます。

![menubar](/stickies-menubar.png)

### 付箋のボタン

| ボタン | 機能 |
|--------|------|
| X | 付箋を閉じる |
| ピンアイコン | 付箋を常に最前面に保つ |
| ^ | 付箋を最小化する |
| ゴミ箱アイコン | 付箋を削除する |
| パレットアイコン | 付箋の色を変更する |
| バインダーアイコン | 付箋の内容をコピーする |

![green-note](/green-note.png)

付箋ウィンドウは上下のバーをドラッグして動かせます。テキスト部分をドラッグしても選択操作の邪魔にはなりません。

### キーボードショートカット（macOS）

| ショートカット | 機能 |
|----------------|------|
| `⌘N` | 新しい付箋を作成する |
| `⇧⌘A` | Organizer（すべての付箋）を開く |
| `⌘⏎` | クイック入力の内容を付箋にする |
| `⌘P` | 選択中の付箋のピン留めを切り替える |
| `⌘M` | 付箋を最小化する |
| `⌘W` | 付箋を閉じる |
| `⌘,` | 設定ウィンドウを開く |
